# 📊 E-Commerce Sales Analysis Dashboard

An interactive **Power BI dashboard** built to analyze e-commerce sales performance, profitability, product categories, customer sales, payment methods, and regional performance.

## 📸 Dashboard Preview

![E-Commerce Sales Dashboard](Madhav%20Store%20Ecommerce%20Data/Images/Dashboard.png)
## 📌 Project Overview

The objective of this project is to transform raw e-commerce transaction data into an interactive business intelligence dashboard that helps users understand sales and profit performance.

### Key areas analyzed

- Total sales amount
- Total quantity
- Average Order Value (AOV)
- Total profit
- Monthly profit trends
- State-wise sales
- Category-wise quantity
- Customer-wise sales
- Payment mode distribution
- Sub-category profitability

## 🎯 Objectives

- Analyze overall e-commerce sales performance.
- Identify high-performing and profitable product categories.
- Compare sales performance across states.
- Understand customer purchasing and payment patterns.
- Analyze monthly profit trends.
- Present business insights through an interactive dashboard.

## 📂 Dataset

The project uses two datasets:

### `Details.csv`

Contains transaction-level information such as:

- Order ID
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- Payment Mode

### `Orders.csv`

Contains order and customer information such as:

- Order ID
- Order Date
- Customer Name
- State
- City

The datasets are related using **Order ID**.

## 💡 Key Insights

Based on the dashboard:

- **Clothing** contributes the largest share of quantity among the displayed categories.
- **COD** is the most frequently used payment mode.
- **Printers** show the highest profit among the displayed sub-categories.
- **Maharashtra** has the highest sales amount among the displayed states.
- Monthly profit can be compared using the interactive quarter filter.
- Customer-level analysis highlights high-value customers.

> Dashboard values and insights may change when filters are applied.

## 🚀 How to Use

1. Clone or download this repository.
2. Open `ECommerce_Sales_Dashboard.pbix` in Microsoft Power BI Desktop.
3. If required, update the CSV file paths.
4. Review the Power Query transformations.
5. Explore the dashboard using the Quarter and State filters.
